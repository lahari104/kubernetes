* Helm is the package manager for K8s.
* It helps us to add dynamic nature to K8s manifests.
* Helm has repositories, the helm repository is the collection helm charts
* When we install a helm repo we will get `templates folder, chart.yaml, helm-charts` and additionally we will get a `values.yaml` and by using this `values.yaml` we can able to give dynamic nature to manifests.
* Whenever we install a helm chart we will get a revisionn with revision number
